# Raka Wirya Kusuma — Portfolio

Personal portfolio website for Raka Wirya Kusuma — Full-Stack Web Developer,
Android App Developer, and aspiring Game Developer based in Jakarta, Indonesia.

## Theme
"Player Card" — an arcade HUD / developer-console aesthetic (graphite black
canvas, cyan–magenta duotone, amber XP accents) built with plain HTML, CSS
and vanilla JavaScript. No build step required.

## Structure
- `index.html` — homepage (hero, about, skills, education, work, contact)
- `projects/` — full projects listing with category filters
- `experience/` — experience timeline
- `404.html` — not found page
- `assets/` — shared CSS, JS and images
- `projects/projects.json` — project data consumed by the site

## Running locally
Just open `index.html` in a browser, or serve the folder with any static
server, e.g.:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000`.
